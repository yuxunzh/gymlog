# 健身记录 GymLog v2.0

手机端健身日志：按日期记录每天训练的部位、动作、每组重量 × 次数。**内置 130+ 常用中文动作，点一下就能记录，不用再每次打字**；重量和组数会自动带入上一次的数值。

## v2 新增（相比第一版）

- **动作库**：按部位内置 130+ 动作（胸/背/肩/腿/臀/手臂/核心/全身/有氧/其他），支持搜索，点选即可
- **我的常练动作**：自动按使用频率排序显示在首页顶部，点一下就按上次的重量、组数记到当天（一个字都不用打）
- **自动带入上次数据**：选中动作后，重量、次数、组数自动填好，直接点保存
- **组数批量填写**：重量 × 次数 × 组数，一次生成多组
- **复制上次训练**：把上一次整套训练一键搬到今天，适合固定计划
- **常练固定**：动作名旁的 ☆ 点一下固定到常用（★）
- **安装横幅**：打开时直接提示安装到主屏幕
- **检查更新** + 版本号显示
- 数据格式向后兼容：**老记录、老备份都不会丢**

## 怎么把它变成手机上的「真 App」

三种方式，从快到稳排列。

### 方式一：安装 PWA（最快，30 秒）

1. 把本文件夹部署到任意静态托管（Netlify / GitHub Pages / Vercel 均可，拖文件夹即可）。
2. 手机浏览器打开网址：
   - **Android（Chrome/Edge）**：菜单 →「安装应用」；或在应用内点顶部横幅的「安装」
   - **iPhone（Safari）**：底部「分享」→「添加到主屏幕」
3. 之后从桌面图标打开：全屏、无浏览器地址栏、断网可用，和普通 App 基本无差别。

> 关键：一定要用 **https 网址**打开，安装入口才会出现；`file://` 或局域网 http 地址不支持安装。

### 方式二：打包成安卓 APK（不用写代码，约 5 分钟）

用 [PWABuilder](https://www.pwabuilder.com)（微软官方工具，免费）：

1. 先完成方式一的第 1 步，拿到你的 https 网址。
2. 打开 PWABuilder，输入网址 → Start。
3. 选择 **Android** → Package for stores → Download。
4. 得到 `app-release-signed.apk`（PWABuilder 会自动生成签名密钥并保留在压缩包里）。
5. 把 APK 传到手机（微信/QQ/数据线都行），点击安装，允许「安装未知来源应用」。
6. 安装后就是独立 App：有自己的图标、启动画面，全屏运行。

> PWABuilder 还会给你一个 `assetlinks.json`：把它放到网址根目录的 `.well-known/` 下，就能隐藏顶部地址栏，体验更接近原生。

### 方式三：用本仓库自带的 GitHub Actions 自动构建 APK（全程自动）

项目里已经配好了 Capacitor 安卓工程和构建流水线，不需要本地装 Android Studio。

1. 把本文件夹整个上传到一个 GitHub 仓库（网页上拖拽即可）。
2. 打开仓库的 **Actions** 标签 → 左侧「构建安卓安装包 APK」→ **Run workflow**。
3. 等约 3–5 分钟，构建完成后在该次运行的页面底部 **Artifacts** 里下载 `健身记录-APK`。
4. 解压得到 `app-debug.apk`，传到手机安装即可。

想自己改安卓工程（换图标、改包名、发布到应用商店）：本地装 Node + Android Studio 后，运行

```
npm install
npm run android:add     # 首次：生成 android/ 工程
npm run android:sync    # 每次改完网页后同步
npm run android:open    # 用 Android Studio 打开并打包正式版
```

> 上架 Google Play 需要用 Android Studio 生成签名的 release APK/AAB，并且要有 Google Play 开发者账号（一次性 25 美元）。

### 关于 iPhone

iOS 不允许安装「未上架商店」的独立安装包，想做原生 App 必须有 Apple 开发者账号（99 美元/年）+ Mac 签名。**iOS 上推荐直接用方式一（添加到主屏幕）**，装上后同样是全屏、离线可用的独立图标。

## 加自己的动作

方法一（不用改代码）：直接在应用里输入动作名保存，之后它会自动出现在「常用」里。

方法二（写进动作库，永久存在）：用记事本打开 `exercises.js`，找到对应部位，加一行：

```js
'胸': [
  '杠铃卧推',
  '器械推胸',   // ← 新增的动作
],
```

保存后重新部署（或在本机刷新页面）即可看到。

## 数据与备份

- 所有数据保存在**当前浏览器/应用的本地存储**中，不上传服务器。
- **只要网址（域名）不变，重新部署新版本不会丢数据**；但如果换网址、清除浏览器数据、卸载应用，数据会丢失。
- 建议定期：「设置 → 导出数据（JSON 备份）」。换手机时导入即可。
- 注意：PWA 版本和 APK 版本是**各自独立的数据**（不同容器）。想迁移就用导出/导入。
